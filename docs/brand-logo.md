# Next Chapter logo

Three directions were explored for the Adon storefront:

1. **Next Chapter (selected):** an open book whose right page becomes a forward,
   upward arrow. Connects practical guides with taking action.
2. **UG Monogram:** angular interlocking initials for a compact technical identity.
3. **Clear Path:** a diagonal arrow leaving a broken square frame, expressing simplicity.

The selected orange mark is used in the header and footer without the former white
background tile. The accessible brand name remains real text next to the image.
Browser icons use new versioned paths to avoid retaining the old icon in caches.

Assets in `public/brand`:
- `next-chapter.webp`: 256px transparent web logo.
- `next-chapter-32.png` and `next-chapter-192.png`: transparent favicons.
- `next-chapter-touch.png`: 180px home-screen icon on the site's charcoal background.

Created with the built-in image-generation tool, then resized for web delivery.
Final generation brief: isolate option 01; retain its left open-book page and right
page/up-right arrow with triangular negative space; orange #FB7515, transparent
background, no text, no other symbols, crisp edges, centered square composition.
The original high-resolution generated artwork and comparison board are available
in the originating conversation.

Validation: production Astro build passes; output assets retain expected dimensions
and transparency (touch icon intentionally has an opaque dark background).
